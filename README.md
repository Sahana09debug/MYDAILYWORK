## 📖 Description
This project is a Tic-Tac-Toe game where a human player competes against an AI opponent.  
It provides a graphical interface using Pygame for interactive gameplay.

## ✨ Features
- Human vs AI gameplay  
- Graphical User Interface (GUI)  
- Mouse-based interaction  
- Displays result (Win / Lose / Draw)  

## 🛠 Technologies Used
- Python  
- Pygame  

## 🚀 How to Run

1. Make sure Python is installed  
2. Install Pygame:

```bash
pip install pygame
```

3. Run the game:

```bash
python main.py
```

# 🎬 Project 3: Movie Recommender System

## 📖 Description
The Movie Recommender System is a Machine Learning project that recommends movies based on similarity scores.  
It uses content-based filtering to suggest movies similar to the selected movie.

The system is deployed using Streamlit for an interactive web application.

## ✨ Features
- Content-based movie recommendation  
- Similarity score calculation  
- Interactive UI using Streamlit  
- Displays top 5 recommended movies  
- Movie poster fetching using TMDB API  

## 🛠 Technologies Used
- Python  
- Pandas  
- NumPy  
- Scikit-learn  
- Streamlit  

## 📂 Project Structure

```
Movie_Recommender/
│
├── app.py
├── movies.pkl
├── similarity.pkl
├── requirements.txt
└── README.md
```

## 🚀 How to Run

```bash
git clone <your-repository-link>
cd Movie_Recommender
pip install -r requirements.txt
streamlit run app.py
```
